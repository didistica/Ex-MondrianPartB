# Destabilização - Random ()

As linhas pretas tremem ligeiramente com random(), e o efeito que resultou foi inesperado: no meu ponto de vista parece os blocos de cores querem "escapar", como se houvesse uma tensão a empurrar de dentro para fora, mas as linhas impedem-nos. 
A estrutura de Mondrian passa assim de moldura de ordem a grelha que prende. As cores ficam em conflito com a estrutura que as contém: tentam escapar e não conseguem.
